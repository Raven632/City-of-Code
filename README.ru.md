# City of Code

[English](README.md) | [Deutsch](README.de.md) | Русский

Браузерная игра, на которой в школе учат Python. Задания решаешь в редакторе кода прямо в браузере,
и с каждым решённым заданием растёт твой собственный маленький город: дома, ратуша, пожарная часть,
больница. Четыре главы идут в обычном для курса Python порядке: переменные, условия, циклы, функции.

Мы делаем её как школьный проект в Friedrich-Dessauer-Schule в Лимбурге (класс BFI 12), с августа
2026 года до сдачи 22 марта 2027.

## Что уже есть

Проект в самом начале. Готово:

- техническое задание (Pflichtenheft) и план проекта (сетевой график с критическим путём)
- проект базы данных, см. [backend/docs/datenbank.md](backend/docs/datenbank.md) (на немецком), и
  ER-диаграмма в `datenbank.dbml`, её можно вставить в dbdiagram.io
- первые экраны фронтенда: регистрация, экраны ученика, учителя и администратора, редактор кода
  (CodeMirror 6) и окно вывода, интерфейс на немецком и английском

Дальше: API на Flask со входом и сам город на Phaser 3, потом запуск и проверка кода учеников через
Pyodide. Первый прототип, в который можно поиграть, должен быть готов к концу ноября 2026.

## Как устроена игра

В игре 20 уровней в 4 главах. В каждом уровне есть задание. Если код верный, уровень открывает одно
или несколько зданий, и их ты сам расставляешь на карте. Следующий уровень открывается, когда всё из
текущего расставлено. Монеты идут только на украшения, так что купить проход дальше нельзя.

Ученики регистрируются по коду класса, который им даёт учитель, и сразу попадают в свой класс.
Учителя увидят, кто в классе насколько продвинулся.

## Как это будет работать

```
 Browser                                     Server (Docker Compose on a VPS)
 ┌─────────────────────────────────┐         ┌──────────────────────────┐
 │ editor (CodeMirror 6)           │  REST   │ Nginx                    │
 │ city (Phaser 3, Tiled maps)     │  + JWT  │ Gunicorn + Flask API     │
 │ Web Worker: Pyodide runs and    │ ──────► │ SQLite via SQLAlchemy    │
 │ checks the student's code       │         └──────────────────────────┘
 └─────────────────────────────────┘
```

Код учеников никогда не уходит на сервер. Он выполняется в браузере через Pyodide (Python,
скомпилированный в WebAssembly) внутри Web Worker, и у каждого уровня есть своя проверка, тоже на
Python, которая запускается там же против решения. Если решение не заканчивается, например
`while True: pass`, воркер останавливается через 5 секунд, а страница продолжает работать. На сервере
хранятся только аккаунты и прогресс.

Решение, которое нам нравится: статус уровня (закрыт, доступен, в работе, ждёт расстановки, пройден)
нигде не хранится. Он вычисляется из нескольких отметок времени, поэтому не может им противоречить.

## Как запустить у себя

Нужны Python 3 и Node.js.

Бэкенд:

```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python seed.py
```

`seed.py` создаёт `instance/codequest.db` заново и заполняет тестовыми данными: учитель, класс с кодом
`AB12CD`, ученик, все 20 уровней и 20 типов зданий. Запускать API пока нечего.

Фронтенд:

```bash
cd frontend
npm install
npm run dev
```

Vite покажет адрес, обычно http://localhost:5173. Пока что есть панель "DEV ROLE SWITCH", чтобы
переключаться между регистрацией и экранами ученика, учителя и администратора.
